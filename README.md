# English Town

Динамичный Vite-сайт с личным профилем ученика и тремя разноуровневыми образовательными играми:

**Онлайн-версия:** https://nikulenkovan1978-spec.github.io/english-town-games/

1. Hello City — интерактивная история из восьми жизненных ситуаций общения.
2. Number Rush — трёхполосный экшен-раннер на числа 1–6.
3. Colorworks — игра на меткость и распознавание цветов.

## Запуск через Vite

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

После запуска Vite автоматически откроет сайт по адресу `http://localhost:5173/`.

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

Музыка и многослойные игровые эффекты создаются через Web Audio. Для английской речи сайт выбирает наиболее естественные доступные английские голоса браузера и отдельно настраивает голоса Leo, Mia, Penny и Archie. Звук включается после создания/открытия профиля, как того требуют браузеры.

Имя, аватар, сердечки, искры, значки и история последних 30 игровых сессий сохраняются в `localStorage`. Для каждой сессии записываются дата, игра, выполненные задания, ошибки, награды и статус завершения.

## Файлы

- `index.html` — точка входа;
- `src/styles.css` — дизайн и адаптивность;
- `src/main.js` — игровая логика, звук, задания и награды;
- `public/assets/heroes/` — оптимизированные игровые WebP-персонажи без фона;
- `public/assets/heroes-v3/` — естественные разговорные позы и новая Penny для раннера;
- `public/assets/worlds-v3/` — иллюстрированные миры главной, Hello City, Number Rush и Colorworks;
- `public/assets/characters/` — исходные изображения персонажей;
- `instrtxt`, `GAME_TASKS_SPEC.md`, `VISUAL_DESIGN_SPEC.md` — исходные требования.

## Проверка

Сайт рассчитан на мышь, клавиатуру и сенсорный экран. В бродилке и раннере работают экранные кнопки и стрелки клавиатуры.
